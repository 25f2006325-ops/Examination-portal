Milestones for Examination Management Portal
Modern Application Development I
Project: Examination Management Portal (MAD-I)
​

The project is divided into 0th milestone, Core Requirements (6 Milestones),
and Recommended Functionalities & Optional Enhancements (5
Milestones).

​

All core milestones can be completed in any order.

​

Recommended and optional enhancements should only be started after the core
milestones are done.

​

Each milestone includes a Git commit message. When completed, use a unique
commit message and push your updates to GitHub.

​

Time estimates are averages. Spend time as needed, to understand and
complete each milestone. Completing Milestone 0 and 6 core requirements are
taken for grading in Viva1. After completing the core requirements, there are 5
additional milestones for enhancements. These enhancements are not graded
but can be completed for improved functionality or to be considered for the Best
Course Project nomination.

​

Students can complete the core milestones in any order as per their approach to
doing the project. They need not follow the same sequence as they appear in this
document.

​

Students can have any number of commits in their project repository, but for a
milestone to be considered as “complete”, the student must make a commit with
a unique commit message of that milestone.

​

It is mandatory to push the entire codebase to GitHub before you submit the code
on the viva-portal.
